# Demo code — Fine-Tuning workshop

Everything the four demos run. All data here is **synthetic and invented** — no real
tickets, names or customer content.

```
demo/
  scripts/   make_data.py  train_lora.py  compare.py  reward.py  eval_agent.py
  data/      generated by make_data.py (already run once)
  checkpoints/  adapters land here
  results/   captured curves and transcripts for the demos shown as results
```

## Setup

```bash
pip install torch transformers peft trl datasets accelerate bitsandbytes
cd scripts && python3 make_data.py --out ../data
```

Pin the base model **the week of the workshop** — export it once and reuse:

```bash
export BASE=<huggingface-id-of-an-8B-instruct-model>
```

## Demo A — make it obey

```bash
python3 train_lora.py --model $BASE --out ../checkpoints/demo-a
ls -lh ../checkpoints/demo-a          # the adapter — this is the moment
```

## Demo B — make it fit

Same script, one flag:

```bash
python3 train_lora.py --model $BASE --out ../checkpoints/demo-b --qlora
python3 compare.py                    # prints the table for the slide
```

Keep `nvidia-smi dmon -s um` in a second pane. Watching memory move is half the lesson.

## Demo C — make it better

```bash
python3 reward.py                     # read this aloud; it fits on one screen
```

Run the RL job **before the workshop** and drop the curve and sampled outputs into
`results/`. Do not run reinforcement learning live.

## Demo D — make it act

```bash
python3 eval_agent.py --model $BASE                                   # before
python3 eval_agent.py --model $BASE --adapter ../checkpoints/demo-d   # after
```

Train the adapter first with `train_lora.py --data ../data/agent_traces.jsonl`.

## Honest status

Data generation and the reward function are **tested and working** — the outputs are
in `data/`. The three GPU scripts are written against current library APIs but have
**not been executed on a GPU from here**. Run each end to end twice on your box before
the day, and write the real numbers into the demo plan.
